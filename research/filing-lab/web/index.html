    Shidduchim

      Benchmark

      Every engine gets the same made-up notes. Two questions are scored separately: did the engine understand the note? and did the note end up in the right place? The filing step is also run on the correct understanding, so a filing mistake can be blamed on the right part.

      How the lab works

      1. The engine reads the note and writes down what it understood, in one shared format: people and roles, activities, answers, my to-dos, and whom I'm waiting for. Engines A and B are real AI models running on this computer. Engine C uses no AI: word lists, a few sentence rules and your saved contacts.
      2. The filing step (ordinary app logic, the same for every engine) matches names to saved contacts, picks the record, works out dates, and sorts every action into: Saved with one tap Needs a choice Needs your OK Just so you know. It never changes data; it only proposes.
      3. The original note is always kept as written. Nothing the engine extracted replaces it.

      What each result card shows is the model's real output, including its mistakes. Open “What the model actually returned” on any card to see it unedited.

      Privacy: the page may only talk to this local server (enforced by the browser), the server listens on 127.0.0.1 only, and the model libraries run in offline mode. The header shows how many network connections the lab has to anything outside this computer.
