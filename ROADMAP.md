## Stage notes
(Claude adds a 2–3 line summary here at the end of each stage: what was built, what's left, known problems.)

- **Stage 0:** Files moved to `source/`. Doc split into `spec/`. Auto-publishing set up from `app/`.
- **Stage 1:** App shell with hash router, top bar + bottom navigation (3- or 4-destination arrangement chosen in Settings), design tokens in `app/css/tokens.css`, IndexedDB store (`app/js/store.js`, schema v1 with all record types from the handoff), 20 fictional starter contacts, Settings with Show labels, Load 200 demo contacts, Remove all demo data, Export / Import / Reset, PWA manifest + service worker (offline, installable). Contacts has a plain list + record view with Pin and a small edit form to prove save → reload; Home / People / Shidduchim / Profile are honest placeholders.
  Left for later stages: real Contacts views, search, sort, filters, folders (Stage 2); everything else per the table. Known: Google Fonts need one online load before they are cached for offline use.
- **Stage 2:** Contacts is a real workspace: search (names, city, roles, notes and conversation text), Sort (recent/oldest conversation, name, city, language, community), role + activity chips, Filters sheet (city, language, community, folder; combinable, removable tags, Clear filters), Pinned section, optional folders (Move to folder / New folder), View picker with all six phone views (A, top/bottom split with drag bar, narrow sidebar, name tabs, expanded list, inbox drill-down), desktop Outlook-style three-area view (≥1024 px; app nav becomes a left column). Selected person: quick facts, Pin, Record conversation (one record per entry, edit/delete), follow-ups, linked people, private notes, attachments. One-screen Add Shadchan / Edit contact with bubbles, three-dot "add", Manage categories & choices (hide/show/delete/reorder), duplicate warning, attachments. Settings: view picker + default sort. Demo contacts now come with fictional conversation history. Fixed: Settings could redraw itself over other pages.
  Left for later: linking conversations to suggested people needs Add Person (Stage 3); Send my profile (Stage 7); folder rename/delete; showing conversations on Home (Stage 6). Known: attachments are kept inside the backup file, so large photos make backups large (5 MB per file limit).
- **Stage 3:** Add Person (`#/people/new`) with Guy / Girl picker and the three tabs. Paste: clipboard button, text box, attach files, "Source · optional", Save for later / Next. Only clearly labelled lines are filled in (name, age, city, occupation, languages, about, looking for, up to age, phone numbers with their owner); nothing is guessed, and `+` country codes become 00. Basic Info: original on the left (stacked on top on narrow phones), name, one card per number with "Whose number is this?" and the seven owner choices, age; Save and Finish / Add More Details. Detailed Info: every section open, sticky jump row, View Original, Contacts & Source cards with pencil editing, optional email, linking to an existing contact (or "Save as a new contact"), recent cities and senders, oval yes-rows (Never married / Divorced exclude each other; Never spoke clears phone / met), three dots open a small inline box, New category with subcategories, Manage categories & choices (Up / Down / Hide / Show / Delete with confirmation, Restore defaults). Originals are kept word for word as versions; duplicate check offers Open existing / Add as updated version / Save as new. Unsaved forms are kept and listed on People & Ideas.
  Theme groundwork: every colour, corner, shadow and font is now a token in `app/css/tokens.css` (old hard-coded values in base and Contacts CSS were moved there too), so a warm theme can later be one extra file.
- **Stage 4:** People & Ideas list (search incl. shadchan names, Guys / Girls / I'm interested / Waiting to hear, Saved for later originals, unsaved forms). Person card in the My Profile layout with Profile / Offers / Notes tabs: facts ("Not recorded" when missing), about, looking for, contacts with correct number ownership, how I know them, originals (all versions, earliest marked) and attachments. Offers: my private interest and their reported response kept separately, each change a dated record with reason and who reported it; formal offer section only shows status (starting one says "coming in Stage 5"). Notes: one shared conversation record that can also link to a shadchan (shows in both histories), follow-ups. Contacts now link to the person card and have "Add a person they suggested". Fictional demo people (one in Hebrew) and one saved-for-later original are loaded with the demo contacts.
  Left for later: formal offers and tries (Stage 5); Home showing these notes (Stage 6); Guys/Girls-only setting for custom fields (deferred in the spec). Known: the original-text pane on Basic Info sits on top instead of left on phones narrower than 520 px, so the cards stay tappable.
- **Stage 5:** Shidduchim (`#/shidduchim`) with the Offers / In Progress / Ended lanes (counts, teal-to-pink selected tab), Compact / Expanded cards, and the 11-segment bar (Offer, References, Dates 1–8, Marriage; dates colour only when marked Happened; skipped references stay gray; ended tries turn gray). Compact cards show two arrow-free answer bubbles (Me / the person) that open a floating panel with Not answered yet / Yes / Thinking / No; once both say Yes the stage and next date replace them. Expanded cards add one-tap Stage (Checking / Dating / Ended) and answer choices, Add update and Open details; every quick change offers Undo. No and Ended ask first (who ended it, optional reason, optional who told you). Dating needs Yes from both; Thinking after dating keeps the match In Progress. Details page (`#/shidduchim/<id>`): same bar with past tries dimmed underneath, Overview (summary, two person cards with their own Answer dropdown and optional "Who told you?", one Shadchan line, References, Try Again only after Ended with 1st / 2nd / 3rd Try naming, Recent history with date and time, Add note, See all history), Dates (friendly "Nov 12 · 7:30 PM", Arrange / edit form with When, Where, Status, private Feedback), History (one shared record for every line, inline Add note, Previous tries expandable with their bar and ending reason). A formal offer starts only from the person card (People & Ideas → Offers → Start a formal offer); the person card shows the short status and links to the record. Make Match says it is not designed yet and points to that path. Four fictional demo shidduchim load with the demo people.
  Open questions kept as questions (spec/shidduchim.md): first segment label, auto-Happened after a past date (not done), the three-tries cap (shown as a note, not enforced), Make Match. Known: the "Me" card shows "My Profile · details come with Stage 7" until the profile exists; Marriage has no action yet.
