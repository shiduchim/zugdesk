## Stage notes
(Claude adds a 2–3 line summary here at the end of each stage: what was built, what's left, known problems.)

- **Stage 0:** Files moved to `source/`. Doc split into `spec/`. Auto-publishing set up from `app/`.
- **Stage 1:** App shell with hash router, top bar + bottom navigation (3- or 4-destination arrangement chosen in Settings), design tokens in `app/css/tokens.css`, IndexedDB store (`app/js/store.js`, schema v1 with all record types from the handoff), 20 fictional starter contacts, Settings with Show labels, Load 200 demo contacts, Remove all demo data, Export / Import / Reset, PWA manifest + service worker (offline, installable). Contacts has a plain list + record view with Pin and a small edit form to prove save → reload; Home / People / Shidduchim / Profile are honest placeholders.
  Left for later stages: real Contacts views, search, sort, filters, folders (Stage 2); everything else per the table. Known: Google Fonts need one online load before they are cached for offline use.
- **Stage 2:** Contacts is a real workspace: search (names, city, roles, notes and conversation text), Sort (recent/oldest conversation, name, city, language, community), role + activity chips, Filters sheet (city, language, community, folder; combinable, removable tags, Clear filters), Pinned section, optional folders (Move to folder / New folder), View picker with all six phone views (A, top/bottom split with drag bar, narrow sidebar, name tabs, expanded list, inbox drill-down), desktop Outlook-style three-area view (≥1024 px; app nav becomes a left column). Selected person: quick facts, Pin, Record conversation (one record per entry, edit/delete), follow-ups, linked people, private notes, attachments. One-screen Add Shadchan / Edit contact with bubbles, three-dot "add", Manage categories & choices (hide/show/delete/reorder), duplicate warning, attachments. Settings: view picker + default sort. Demo contacts now come with fictional conversation history. Fixed: Settings could redraw itself over other pages.
  Left for later: linking conversations to suggested people needs Add Person (Stage 3); Send my profile (Stage 7); folder rename/delete; showing conversations on Home (Stage 6). Known: attachments are kept inside the backup file, so large photos make backups large (5 MB per file limit).
- **Stage 3:** Add Person (`#/people/new`) with Guy / Girl picker and the three tabs. Paste: clipboard button, text box, attach files, "Source · optional", Save for later / Next. Only clearly labelled lines are filled in (name, age, city, occupation, languages, about, looking for, up to age, phone numbers with their owner); nothing is guessed, and `+` country codes become 00. Basic Info: original on the left (stacked on top on narrow phones), name, one card per number with "Whose number is this?" and the seven owner choices, age; Save and Finish / Add More Details. Detailed Info: every section open, sticky jump row, View Original, Contacts & Source cards with pencil editing, optional email, linking to an existing contact (or "Save as a new contact"), recent cities and senders, oval yes-rows (Never married / Divorced exclude each other; Never spoke clears phone / met), three dots open a small inline box, New category with subcategories, Manage categories & choices (Up / Down / Hide / Show / Delete with confirmation, Restore defaults). Originals are kept word for word as versions; duplicate check offers Open existing / Add as updated version / Save as new. Unsaved forms are kept and listed on People & Ideas.
  Theme groundwork: every colour, corner, shadow and font is now a token in `app/css/tokens.css` (old hard-coded values in base and Contacts CSS were moved there too), so a warm theme can later be one extra file.
- **Stage 4:** People & Ideas list (search incl. shadchan names, Guys / Girls / I'm interested / Waiting to hear, Saved for later originals, unsaved forms). Person card in the My Profile layout with Profile / Offers / Notes tabs: facts ("Not recorded" when missing), about, looking for, contacts with correct number ownership, how I know them, originals (all versions, earliest marked) and attachments. Offers: my private interest and their reported response kept separately, each change a dated record with reason and who reported it; formal offer section only shows status (starting one says "coming in Stage 5"). Notes: one shared conversation record that can also link to a shadchan (shows in both histories), follow-ups. Contacts now link to the person card and have "Add a person they suggested". Fictional demo people (one in Hebrew) and one saved-for-later original are loaded with the demo contacts.
  Left for later: formal offers and tries (Stage 5); Home showing these notes (Stage 6); Guys/Girls-only setting for custom fields (deferred in the spec). Known: the original-text pane on Basic Info sits on top instead of left on phones narrower than 520 px, so the cards stay tappable.
- **Stage 5:** Shidduchim (`#/shidduchim`) with the Offers / In Progress / Ended lanes (counts, teal-to-pink selected tab), Compact / Expanded cards, and the 11-segment bar (Offer, References, Dates 1–8, Marriage; dates colour only when marked Happened; skipped references stay gray; ended tries turn gray). Compact cards show two arrow-free answer bubbles (Me / the person) that open a floating panel with Not answered yet / Yes / Thinking / No; once both say Yes the stage and next date replace them. Expanded cards add one-tap Stage (Checking / Dating / Ended) and answer choices, Add update and Open details; every quick change offers Undo. No and Ended ask first (who ended it, optional reason, optional who told you). Dating needs Yes from both; Thinking after dating keeps the match In Progress. Details page (`#/shidduchim/<id>`): same bar with past tries dimmed underneath, Overview (summary, two person cards with their own Answer dropdown and optional "Who told you?", one Shadchan line, References, Try Again only after Ended with 1st / 2nd / 3rd Try naming, Recent history with date and time, Add note, See all history), Dates (friendly "Nov 12 · 7:30 PM", Arrange / edit form with When, Where, Status, private Feedback), History (one shared record for every line, inline Add note, Previous tries expandable with their bar and ending reason). A formal offer starts only from the person card (People & Ideas → Offers → Start a formal offer); the person card shows the short status and links to the record. Make Match says it is not designed yet and points to that path. Four fictional demo shidduchim load with the demo people.
  Open questions kept as questions (spec/shidduchim.md): first segment label, auto-Happened after a past date (not done), the three-tries cap (shown as a note, not enforced), Make Match. Known: the "Me" card shows "My Profile · details come with Stage 7" until the profile exists; Marriage has no action yet.
- **Stage 6:** Real Home (`#/home`, layout from Home v8 in the Claude look): search across notes, people, contacts, conversations, follow-ups and history; New Note (optional title, small text Pin, tiny Suggestions dot, Actions / Link Contact / Follow Up / Save Note once you start writing). A note is one record; each dated update is a conversation record linked to the note's people, so the same words show in Home, the contact's history and the person card (with an "Open Home note" link) — editing it anywhere edits it everywhere. Smart Suggestions are simple offline rules (not AI), max three, never required: link a recognised contact/person (ambiguous names ask "Which …?"), create a minimal contact from an unknown name (name only), add a dated update to the one matching note (or pick when several match), one-tap Follow Up using a typed date ("in two weeks", "tomorrow", "Thursday"), waiting items, and "Review X's answer → No/Yes" which needs a clear Yes and keeps who reported it (ends the shidduch with history, or records a reported response if there is no shidduch). Actions dropdown: Follow Up details, Add to an existing note, Waiting for someone, Create new contact, Delete note, six colour swatches (new note = on save; existing note = at once and logged in History). Pinned / Other Notes; desktop click or phone "Add to note" opens the note in place with dated dividers and an inline editor. Follow Ups (first 10, See all / Show less, circle to complete with Undo, tap text to edit) and History (latest 5, See all in steps of 50, chevron opens full text and a shortcut). New small `activity` store (database v2) only for changes with no record of their own (colour, links, contacts made from notes). Fictional demo notes and follow-ups.
  Known: inline highlighting is approximate on very long notes; rules recognise English phrasing best (Hebrew names are matched, Hebrew time phrases are not yet).
- **Stage 7:** My Profile (`#/profile`, `/short`, `/notes`) in the original Claude layout: name, EN/HE language picker (each language keeps its own text; untranslated text shows grey; nothing is auto-translated), edit pencil, Share. Profile tab: summary, Facts (edit / reorder / remove, Add a fact…), About me, What I'm looking for, Contact (inquiries = shared; own phone and email = you choose), custom sections (Add section…, can be kept out of sharing), References (with private notes that are never shared) and Files (photos / PDF, 5 MB each). Desktop gets the left section navigator. Short versions: Suggested (automatic, always up to date; gear chooses its facts), saved versions (Copy, edit, Share, Duplicate, Delete with Undo, New short version). Notes: private notes that save as you type, linked to you, "add people" afterwards; they are the same notes as Home (one record). Sharing activity lists every confirmed send with its exact snapshot. Share sheet: choose text, optional recipient, tick extras (all off by default), exact preview, then Copy / WhatsApp / Email / More…; it is recorded only after "Yes, I sent it" and never claims delivery or reading. Contacts' "Send my profile" opens it for that contact and the send appears in their history; the Shidduchim "Me" card now shows the profile. A fictional example profile loads with the demo data; the first real edit makes it the owner's own record.
  Left / open (spec MP-09): more languages, frozen vs. template short versions (saved versions are kept as written), dark Notes look (kept light for now).
- **Stage 8:** Every workflow in spec/build-handoff.md section D was scripted with Playwright (phone 360 px with touch, desktop 1280 px) plus a smoke pass of every page at 320 / 360 / 390 / 430 / 1280 px: no horizontal overflow, no JavaScript errors. All ten workflows PASS. Fixed or changed on the way: Contacts gained the "Active" status chip (handoff asked for it); notes can now be deleted from Home (on the card and in the open note) and from My Profile → Notes; "People & Ideas" is now "Ideas" with a list icon, and Shidduchim carries the heart; every sheet's Close button moved to the bottom row next to Save; My Profile "Add a fact…" adds facts right on the page, one after another, with no popup; the language choice left the profile header and sits on each short version (Suggested follows it, saved versions keep their own); Home on a phone now has three tabs under New Note (Notes / Follow Ups / History, one at a time, with counts) while the computer keeps the columns; each section has its own header band and History is tinted. Test scripts live outside the repo (no build step added).
  Still missing / open: Make Match (not designed); Marriage segment has no action; the three-tries cap is a note only; the owner reported the word "null" above a Shidduchim progress bar — not reproduced with demo data, needs the element label (Settings → Show labels); pasted originals are kept word for word, so a "+" in a pasted phone number stays inside the original text (the saved number itself uses 00); folder rename/delete; Hebrew time phrases in Smart Suggestions; Guys/Girls-only custom fields.
- **Tweak batch (clean-up):** Dark is the default. One menu only: the slim icon bar with five icons (words come back in the computer's left column); Claude style, Bottom menu and the three-destination choice were removed. Contacts: the top/bottom split view was removed; the two bubble rows became one menu next to Sort; Filters and View are icon buttons; under the person, Edit / Move to folder / Send my profile are text links, Pin is an icon, and the conversation type is a menu. A new phone starts empty; "Try the demo" (Contacts or Settings) loads 200 fictional contacts with ideas, shidduchim, notes and an example profile. My Profile: Suggested short version moved to the bottom, outlined and marked Experimental. Shidduch details: swipe between Overview / Dates / History.
- **Stage S1 (Shadchan Mode foundation):** Settings has a Mode choice (Single · Shadchan); one tap switches and the app remembers it. Shadchan Mode has its own database, so the two modes never mix, and its own bottom bar: Home · Guys · Girls · Shidduchim · Contacts. Home, Contacts, Add Person and the person card work in it unchanged; Guys and Girls are plain lists for now (with To file and unsaved forms). Deleting in Shadchan Mode goes to Settings → Recently deleted for 30 days (Restore puts back a single together with originals, follow-ups and links). One backup file holds both modes; old backups still load. Fonts are inside the app (no Google Fonts). The app asks the browser to keep its storage permanently. Demo: 60 fictional singles, 12 contacts, notes and follow-ups.
  Left for later: search, filters, Working on / All, status and Talk to on the card (S2); Shidduchim is a "coming in S3" page; Home blocks (S4). Known: the Guys / Girls lists show everyone with no search yet; Single Mode still deletes at once (unchanged on purpose).
- **Stage S2 (Guys and Girls):** Search finds any word, also inside the pasted originals (a row found only there shows the words around it). Working on / All with counts. Filters: age from–to, status, city, background, languages (only choices the list really has); they show as removable tags with Clear filters. With an age filter on, singles with no age are listed apart under "Age not recorded", never hidden. Rows load while scrolling (tested with 3,000 singles: search under 20 ms). To file shows 3 with "Show all". The single's card has a Shadchan panel on Profile: Status (Busy asks "check again on …" and makes a follow-up), Working on star, looking-for ages from–to (also in Add Person), Talk to (from the single's numbers), Last confirmed looking with "Still looking — today", and Find a match (says "coming in S5").
  Left for later: the "open shidduch" dot on rows is wired but shows only once S3 makes shidduchim; Busy is not yet set by itself while dating (S3). Known: WhatsApp Share-to-app on Android is not built (needs testing on a phone).
- **Stage S3 (Shidduchim with two sides):** Shidduchim has four lanes: Ideas · Offers · In Progress · Ended. One card per couple with an answer bubble for his side and her side (Not asked · Asked · Thinking · Yes · No), the progress bar ending in Engaged, and either "Your move" or the days waiting. A shidduch moves between lanes by itself as answers and dates are marked; every change offers Undo. New idea: choose a guy and a girl; a couple that was already put together shows a warning with what happened, and no second record is made. One shidduch's page: a "your move" line with its one-tap button, a card per side (the single, whom you talk to with the number, the answer, who told you), references, dates with both sides' answers and private feedback after each one, history, Try Again, End (who ended it, reason, and who was already told), Engaged, Delete. While a couple is dating both are marked Busy by themselves and freed when it ends; Engaged marks both Engaged. The single's card has a real Shidduchim tab. A single with an open shidduch cannot be deleted. Search finds a shidduch by either single or by a contact on their cards. Twelve fictional demo shidduchim.
  Decisions made while building (easy to change): an engaged couple sits in Ended with a gold Engaged label; an idea does not light the "open shidduch" dot; arranging a date marks both sides Yes; a second try starts as an idea again.
  Left for later: Home's To do from these cards and the backup reminder (S4); sending a profile, which will mark a side Asked by itself, and "Not a fit" (S5). Known: reminders only show inside the app.
- **Stage S4 (Home from blocks):** Shadchan Home is a column of blocks under search and New Note: To do (Your move with its one tap: mark asked, Arrange Date n, “… was told”; Waiting for them, oldest first, with Remind (WhatsApp to the Talk to number, or Copy; nothing is recorded) and Got an answer (Thinking / Yes, or No through the End sheet); then My follow-ups as before), At a glance (Open, Waiting, Dating, Ideas, and No open shidduch: starred singles with nothing in Offers or In Progress), Notes, My singles (hidden at first: one line each with what is next) and History (hidden at first). Edit Home (bottom of Home and Settings → Home): show/hide and Up / Down per block, Back to the first layout; all hidden shows “Your Home is empty”. The order is a device setting kept in backups. Backup reminder line when no backup or older than 14 days, with Back up now. Home search also finds shidduchim by either single. Single Mode Home is unchanged.
  Left for later: tapping a No-open-shidduch single opens their card (Find a match is S5); the two-sided “Review X’s answer” smart suggestion is still off in Shadchan Mode.
